# Omarchy VPN

Плагин для бара [Omarchy](https://omarchy.org) — переключатель AmneziaWG/WireGuard
прямо в баре: список серверов, подключение в один клик, добавление сервера по
`vpn://` ссылке или обычному конфигу WireGuard.

## Возможности

- Иконка в баре с индикацией статуса (подключено/отключено/переключение)
- Список сохранённых серверов, подключение кликом
- Добавление сервера: вставляешь `vpn://...` (формат AmneziaVPN) или сырой
  `[Interface]/[Peer]` конфиг — остальное парсится автоматически
- Управление интерфейсом идёт через `awg-quick` с точечным `sudo`-правилом
  (без пароля разрешён только запуск `omarchy-vpn-ctl`, никакой произвольный sudo)

## Зависимости

- `amneziawg-tools` (`awg`, `awg-quick`)
- `gum`, `jq`, `python3`
- Omarchy с Quickshell-баром

## Установка

```bash
git clone <URL_РЕПОЗИТОРИЯ>.git
cd omarchy-vpn
./install.sh
```

Скрипт:
1. копирует `vpn.qml` в `~/.config/omarchy/bar/modules/`
2. ставит `omarchy-vpn-ctl`, `omarchy-vpn-servers`, `omarchy-vpn-add-server` в `/usr/local/bin`
3. добавляет `/etc/sudoers.d/omarchy-vpn` (позволяет запускать только `omarchy-vpn-ctl` без пароля)
4. проверяет, есть ли модуль `vpn` в `~/.config/omarchy/shell.json`, и если нет — подсказывает, что добавить
5. перезапускает бар (`omarchy-restart-shell`)

Если модуля `vpn` не было в `shell.json`, добавь его вручную в массив `modules` секции бара:

```json
{ "id": "vpn", "type": "qml" }
```

## Использование

- Левый клик по иконке — открыть панель со списком серверов
- Средний клик — включить/выключить VPN (последний выбранный/активный сервер)
- Правый клик — обновить статус и список серверов
- «+ Добавить сервер» — открывает плавающий терминал, куда вставляется ссылка/конфиг

## Удаление

```bash
./uninstall.sh
```

Сохранённые конфиги серверов (`~/.config/omarchy/vpn/servers.json`,
`/etc/amnezia/amneziawg/*.conf`) не трогаются — удаляй вручную при необходимости.

## Безопасность

`omarchy-vpn-ctl` валидирует имя интерфейса регуляркой перед любым обращением
к файловой системе или `awg-quick`, поэтому пользовательский ввод (метка
сервера, id) не попадает в shell как есть. Root-права нужны только для
поднятия/опускания WireGuard-интерфейса — сам разбор конфигов и хранение
списка серверов выполняется от обычного пользователя.
