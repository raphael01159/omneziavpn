# OmneziaVpn

Плагин для бара [Omarchy](https://omarchy.org) — переключатель AmneziaWG/WireGuard
прямо в баре: список серверов, статистика соединения, подключение в один клик,
импорт по `vpn://` ссылке или обычному конфигу WireGuard.

Ставится штатно, одной командой, через менеджер плагинов Omarchy
(`omarchy plugin add`) — подробности в разделе «Установка».

## Возможности

- Иконка в баре с индикацией статуса (подключено/отключено/переключение)
- Список сохранённых серверов, подключение кликом
- Добавление сервера: вставляешь `vpn://...` (формат AmneziaVPN) или сырой
  `[Interface]/[Peer]` конфиг — остальное парсится автоматически
- Переименование и удаление серверов прямо из панели
- Трафик и время последнего рукопожатия для активного соединения
- Системные уведомления при подключении/отключении/ошибке
- Опциональное автоподключение к последнему серверу при старте бара
  (настройка плагина в Omarchy, по умолчанию выключено)
- Управление интерфейсом идёт через `awg-quick` с точечным `sudo`-правилом
  (без пароля разрешён только запуск `omarchy-vpn-ctl`, никакой произвольный sudo)

## Зависимости

- `amneziawg-tools` (`awg`, `awg-quick`)
- `gum`, `jq`, `python3`
- `libnotify` (`notify-send`) — опционально, для уведомлений
- Omarchy с Quickshell-баром

## Установка

Это настоящий плагин Omarchy (`manifest.json`, `kinds: ["bar-widget"]`) —
ставится штатным менеджером плагинов:

```bash
omarchy plugin add https://github.com/raphael01159/omneziavpn.git --enable --yes
```

Виджет появится в баре, но VPN пока не заработает — плагины не получают
sudo и не трогают systemd, поэтому root-часть (управляющие скрипты и
sudoers-правило) ставится отдельным шагом:

```bash
cd ~/.config/omarchy/plugins/raphael01159.omneziavpn
./install.sh
```

Скрипт проверяет зависимости и ставит `omarchy-vpn-ctl`,
`omarchy-vpn-servers`, `omarchy-vpn-add-server`, `omarchy-vpn-rename-server`
в `/usr/local/bin` плюс `/etc/sudoers.d/omarchy-vpn` (разрешает пользователю,
который запускает install.sh, без пароля запускать только
`/usr/local/bin/omarchy-vpn-ctl`, ничего больше).

Автоподключение к последнему серверу при старте бара включается через
настройки плагина в Omarchy (Setup → Plugins → OmneziaVpn), поле
«Автоподключение при старте бара».

### Обновление / удаление

```bash
omarchy plugin update raphael01159.omneziavpn
~/.config/omarchy/plugins/raphael01159.omneziavpn/uninstall.sh   # бэкенд, перед удалением плагина
omarchy plugin remove raphael01159.omneziavpn                    # сам виджет
```

## Использование

- Левый клик по иконке — открыть панель со списком серверов
- Средний клик — включить/выключить VPN (последний выбранный/активный сервер)
- Правый клик — обновить статус и список серверов
- «+ Добавить сервер» — плавающий терминал, куда вставляется ссылка/конфиг
- ✎ рядом с сервером — переименовать, × — удалить
- Пока сервер подключён, под статусом видно `↓ трафик ↑ трафик · рукопожатие N назад`

## Безопасность

`omarchy-vpn-ctl` валидирует имя интерфейса регуляркой перед любым обращением
к файловой системе или `awg-quick`, поэтому пользовательский ввод (метка
сервера, id) не попадает в shell как есть. Root-права нужны только для
поднятия/опускания WireGuard-интерфейса и чтения статистики соединения —
сам разбор конфигов и хранение списка серверов выполняется от обычного
пользователя. Плагин выполняется как обычный QML-код внутри `omarchy-shell`
без песочницы — просматривай код перед установкой, как и любой сторонний
плагин.

## Производительность

- Статус и статистика соединения получаются одним вызовом `awg show <iface>
  dump` вместо отдельных запросов трафика и рукопожатия.
- Активный интерфейс определяется через `awg show interfaces` (один процесс),
  а не перебором `awg show <name>` по каждому сохранённому серверу.
- Опрос статуса идёт раз в 20 секунд, пока панель закрыта, и раз в 3 секунды,
  пока она открыта — фоновая нагрузка минимальна, а открытая панель обновляется
  быстро.
